# TestForge

AI-Powered API Testing & Regression Platform

## Vision

TestForge is a developer platform that understands APIs,
generates structured test cases using AI, executes tests,
validates responses deterministically, analyzes failures,
and maintains reusable regression test suites.

## Tech Stack

- Next.js
- TypeScript
- Fastify
- PostgreSQL
- Prisma
- Redis
- BullMQ
- Docker
- LLM APIs
